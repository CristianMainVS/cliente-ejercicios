## 📖 Sobre este repositorio

Aquí reúno las prácticas, ejercicios y proyectos que voy desarrollando en la asignatura **Desarrollo Web en Entorno Cliente** del ciclo de Desarrollo de Aplicaciones Web (DAW). El objetivo es aprender a programar la parte del cliente: JavaScript, manipulación del DOM, eventos, formularios y comunicación con servidores.
